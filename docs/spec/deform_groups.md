# 工厂结构可变形子集（DeformGroup）

本文记录活塞伸缩用的结构图、`DeformGroup` 聚合规则，以及校验用例的完整计算过程。实现见 [`structure_state.rs`](../../crates/oif-sim/src/simulation/structure_state.rs)；单测 `deform_figure_a_three_parallel` / `deform_figure_b_bent` / `deform_face_to_face_includes_back_cargo` / `deform_parallel_gap_fork_independent` 对应图 A / B / C / D。

## 结构图（编辑期构建，按结构缓存）

- 节点：工厂实体块 `BlockId` + 每个推杆的**逻辑头** `BlockId`（放置时分配，伸出前后同一 ID）
- 边：
  - **有向**：仅 `body → head`（可切断的伸缩边）
  - **无向**：头连正面邻块；体的其余五面邻块连在体上
  - **注意**：若两格已因「A 的头—A 正面（B）」相连，不再额外加 B 侧面回到 A 的体—体边（否则图 B 会误出 `1—3` / `3—5`）
  - **贴脸对向**：两杆正面互指时无向边为头—头；是否纳入对面体由「对面是否切断」的 fork 候选决定

```rust
/// 共轴可变形子集：同节点集 + 同轴的动作必须一起伸缩
struct DeformGroup {
    actions: Vec<(BlockId, bool)>, // (活塞体 ID, true=正推 / false=反推)
    nodes: Vec<BlockId>,           // 有序，便于相等比较
}
// action_to_groups: (body, forward) → Vec<group_index>，按 nodes.len() 升序
```

构建步骤（结构变脏时）：

1. 由成员与 `head_of` 建邻接（有向 `body→head`，其余无向）
2. 对每个活塞 `P`，在**同轴**同伴上枚举「也切断」子集（东西只与东西、南北只与南北）；每种子集下正推从 head、反推从 body 传播（未切断的有向边可双向走；碰到本杆切开另一端=成环丢弃）
3. 每个成功节点集都是该动作的一条候选；相同 `(nodes, 世界推动方向)` 的动作聚成一个 `DeformGroup`（正推用 facing，反推用 -facing；对向环「西正=东反」同向故共组，同朝向链上「中反≠后正」不共组）
4. `action_to_groups` 按节点数升序；运行时**优先试较小节点集**（更多活塞同时推出）
5. **共轴组可用性**：若组内某同伴动作的体不在该组 `nodes` 中（说明该候选假定同伴也切断），则本回合该同伴必须同样在伸/缩，否则跳过该组、改试更大的独立候选

单切同轴全失败时：全切所有体–头边后仅无向再传（对向环）。

## 运行时 held

每回合临时（不进存档）：

- `held_blocks`：本回合已标记移动中的块（含逻辑头）
- 先执行的正/反推成功后写入 `held`；后执行者目标集与 `held` 相交则试下一条候选，都失败则整杆失败
- 结构整段平移与「撞墙」一样：每回合一结构一方向

## 理解校验

### 图 A — 三平行推杆

```
➡️⬛
➡️⬛
➡️⬛
```

```
1 → 2 — 3
|       |
4 → 5 — 6
|       |
7 → 8 — 9
```

不切断同伴时从正面列走进体列会绕回本杆 → 成环丢弃；仅「三杆同切」存活：

```text
actions=[(1,true),(4,true),(7,true)]  nodes=[2,3,5,6,8,9]
actions=[(1,false),(4,false),(7,false)] nodes=[1,4,7]
```

### 图 B — 折角三杆

```
➡️⬇️
空⬅️
```

```text
(0,0) 1→  2(head)    (1,0) 3↓  4(head)
(0,1) 空              (1,1) 5←  6(head)
```

边：有向 `1→2,3→4,5→6`；无向 `2—3,4—5`。链：`1 → 2 — 3 → 4 — 5 → 6`。

同轴同伴（1 与 5 皆东西向）会 fork 出多条候选；文档中的「最大成功集」仍须存在：

| 动作 | 须存在的成功节点集 |
| --- | --- |
| `(1,true)` | `{2,3,4,5,6}`（另可有更小 fork） |
| `(1,false)` | `{1}` |
| `(3,true)` | `{4,5,6}` |
| `(3,false)` | `{3,1,2}` |
| `(5,true)` | `{6}` |
| `(5,false)` | `{5,4,3,1,2}` |

### 图 C — 贴脸对向 + 背面货物

```text
z=0  6↓  23(head)
z=1  4↑  22(head)
z=2  7(Wire)
```

`6 → 23 — 22 ← 4 — 7`（同轴南北）

| 动作 | 候选（须含） |
| --- | --- |
| `(6,true)` | `{22,23}`（两杆同切）；`{22,23,4,7}`（只切 6） |
| `(6,false)` | `{6}` |
| `(4,true)` | `{22,23}`；`{22,23,6}` |
| `(4,false)` | `{4,7}`（及可能的更深 fork） |

### 图 D — 平行双杆正面列相连（体不相邻）

```text
11 → 21 — 8
           |
          9
           |
13 → 22 — 10
```

| 动作 | 候选 |
| --- | --- |
| `(11,true)` / `(13,true)` 共轴 | `{8,9,10,21,22}`（优先） |
| `(11,true)` 独立 | `{8,9,10,21,22,13}` |
| `(13,true)` 独立 | `{8,9,10,21,22,11}` |
| `(11,false)` / `(13,false)` | `{11}` / `{13}` |
